## 5. Arah Visual

Gabungan **design system Flat** (prompt) + **mood scrapbook** (gambar referensi 2).

**Diambil dari referensi (gambar 2):**
- Latar kertas bergaris/grid halus
- Elemen "sticker" dan label kecil berwarna (tag miring)
- Foto gaya **polaroid** dengan "selotip"
- Judul pixel font besar
- Catatan kertas warna-warni (sticky note) untuk fakta cepat
- Susunan sedikit miring (rotate ±2–4°) agar terasa ditempel

**Disesuaikan agar patuh design system Flat:**
- **Tanpa box-shadow, tanpa blur, tanpa gradient pada kartu.** Polaroid = kotak putih + `border-4` gelap, bukan bayangan.
- "Selotip" = persegi panjang flat semi-transparan (warna solid, opacity), bukan tekstur.
- Sticker = blok warna solid, `rounded-md`, teks uppercase `tracking-wider`.
- Grid paper = pola garis `#E5E7EB` sangat tipis sebagai dekorasi latar (bukan divider).
- Pemisah antar-section = **ganti warna blok**, bukan garis.

**Tipografi**
- Body & UI: **Outfit** (400 / 500 / 600)
- Heading section: **Outfit 800**, `letter-spacing: -0.02em`
- Display khusus hero "PORTOFOLIO" dan label kecil: **Pixelify Sans** (Google Fonts) → memberi nuansa game, sesuai referensi. Pakai hemat (hero + 1–2 aksen).
- Fallback: `system-ui, sans-serif`

**Palette** (dari design system)
`#FFFFFF` bg · `#111827` fg · `#3B82F6` primary · `#10B981` secondary · `#F59E0B` accent · `#F3F4F6` muted · `#E5E7EB` border

Cek kontras: teks **putih hanya di atas Blue/Dark**. Di atas Amber dan Emerald pakai teks `#111827`.

**Motion**: `transition-all duration-200`; hover tombol `scale-105`, kartu `scale-[1.02]`; sticker bisa "goyang" kecil saat hover (rotate berubah). Hormati `prefers-reduced-motion`.
